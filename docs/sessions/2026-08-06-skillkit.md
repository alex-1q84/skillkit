### 1.3 关键决策 / 约束（改样式必读）

- **CSS 只增不改共享 class**：`.chip` / `.badge` / `button.x` 等被 sources/projects/profiles 复用，新样式全用新 class（`.tag` / `.pill-btn` / `.cell-id` / `.skills-table` / `a.chip`），避免波及其他页面。

## 3. 关键背景

### 3.1 demo 风格与真实数据的差异

- **computed_hash 长度**：demo 是短 hash（7 位示意），真实 registry 是 64 位 sha256。已用 ellipsis 截断 + `title` 完整值兜底，否则表格撑爆。
- **managed vs unmanaged**：真实 `~/.skillkit/registry.json` 大多 skill 是 unmanaged（`computed_hash`/`version` 为 None）——unmanaged tag 会出现大量红色标签（实测 69 个），这是真实数据现状，非样式 bug。
- **表格列多（7 列）**：窄屏会横向滚动，现未做响应式折叠（demo 也如此，YAGNI）。

### 3.2 改 CSS 生效链路（高频踩坑）

```
改 app.css / Askama 模板 → cargo build -p skillkit-cli（rust-embed 重新打包）
→ pkill -f "target/debug/skillkit serve" → 重启 serve → 浏览器强刷（token 变了）
```
不重建二进制只重启 serve，CSS/模板变更不生效（旧 bin 嵌入旧资源）。

### 3.3 GUI 调试（playwright）

- playwright 装在 `~/.local/pipx/venvs/playwright/bin/python`（非项目依赖，不进 Cargo.toml）。
- SSE 长连接导致 `wait_until="networkidle"` 永不空闲，**必须用 `wait_until="load"`**。
- 截图读取在部分工具报「Unsupported Image」，改用 DOM 断言（`getComputedStyle` 查 padding/border-radius/背景色）验证样式生效。
