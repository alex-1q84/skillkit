## 3. 关键背景

### 3.1 默认多 agent + scan_shared 共享池（本次核心，改 Config/scan_shared 时必读）

- `Config::default()` = claude-code（supports_symlink=true, reads_agents_dir=false）+ cursor + codex（均 supports_symlink=false, reads_agents_dir=true）。`Config::load` 无 config.toml 时走 default。
- `scan_shared(root, agents)`：遍历 agents 各 `.<agent_dir_name(agent)>/skills`（claude-code→claude，其余原样），再额外扫 `<root>/.agents/skills`（共享池，归属 `agents/<name>`）。过滤：真实目录、非 symlink、无 `.skillkit-sha`（local 标记跳过）。抽 `collect_shared(root, dir, label, found)` helper。
- `sync_agents` handler（`crates/server/src/routes/projects.rs`）：`proj.agents = Config::load().agents.names` → save → `render_workspace`。复用 add handler 取 agent 列表的逻辑。
- GUI/CLI agents 来源：GUI 注册 / CLI `project add` 留空均取 Config 全 agent；旧项目用 sync-agents 补全。CLI 全仓不调 scan_shared（仅 GUI render_workspace 一处调）。
