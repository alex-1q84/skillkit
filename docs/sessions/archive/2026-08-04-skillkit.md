## 3. 关键背景

### 3.1 htmx hx-swap 继承（改 Projects 浮层必读）

- htmx 的 `hx-target` / `hx-swap` **从最近祖先继承**。按钮在 `<form hx-swap="outerHTML">` 内、自己没写 hx-swap → 继承 form 的 outerHTML。
- 后果：outerHTML swap 把整个 target（如 `#browse-panel-add`）替换为响应；若响应顶层无 id，挂载点 id 丢失，后续 `hx-target="#挂载点"` 找不到。
- 规则：触发浮层的按钮显式 `hx-swap="innerHTML"`（挂载点保留，浮层为子节点）。浮层 fixed 定位照常全屏遮罩。

### 3.2 路径解析 + Tab 补全 + toggle

- `resolve_dir(Option<&str>)`（projects.rs 私有 fn）：空/`~` → home；`~/x` → home/x；否则 canonicalize（失败用原值）。browse/scan/complete/toggle 共用。
- Tab 补全前缀匹配：输入 P，尾斜杠或空 → base=P prefix=""; 否则 base=parent prefix=末段。列 base 子目录过滤 prefix。补全带尾斜杠（逐级续补）。
- toggle / add 注册前都按 **canonical 全路径精确匹配**查重（`project.path == abs_str`）。
- `complete.html` 候选 `data-path="{{ c.full }}/"`（带尾斜杠）。

### 3.3 GUI 调试（playwright）

- `e2e/fixtures.py` 提供 `new_browser()` / `wait_for_serve()` / `open_page()`（chromium）。`e2e/test_ui.py` 是 `make e2e` 入口。
- 临时复现脚本：写 `/tmp/x.py`，`sys.path.insert(0,'e2e'); from fixtures import new_browser`，`page.on('pageerror'/'console')` 抓错误，`eval_on_selector` 查 DOM，`page.on('request'/'response')` 抓 htmx 请求。serve 后台起后 token 从输出文件 grep `[0-9a-f]{32}`。
- playwright 装在 `~/.local`（本次调试 `pip install playwright` + `playwright install chromium`），非项目依赖，不进 Cargo.toml/Brewfile。

### 3.4 浮层关闭 + scan 浮层保活（layout.html script）

- `closeBrowseOverlay(overlay)`：✕/遮罩/ESC → remove。scan-flyout 关闭后补刷 main（同步已注册列表）。
- SSE `changed`：scan 浮层开时 `if (document.querySelector('.scan-flyout')) return`（跳过，避免注册写 toml 触发 SSE 清浮层，破坏连续 toggle）。
- Tab 补全：afterSettle 幂等重绑（`data-complete-bound` 防重复，仿 Sortable）。
