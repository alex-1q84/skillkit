# skillkit M0 骨架实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭起 skillkit 的 Cargo workspace 骨架（core 库 + CLI 薄壳），跑通 source 管理、install/uninstall、全局 skill 的 Claude symlink 桥接——装一个 git 源 skill 后 Claude 能直接加载。

**Architecture:** 三层共享 core（CLAUDE.md §3）。`skillkit-core` crate 承载全部业务逻辑，`skillkit-cli` 是 clap 薄壳调 core。路径解析做成 `Paths` 结构（生产用 `dirs::home_dir()`，测试注入 tempdir），保证可测且不硬编码。git 操作走 `std::process::Command` 调系统 git（skill 源本就是 git，系统 git 必然存在）。

**Tech Stack:** Rust edition 2021 · clap(derive) · serde + serde_json + toml · thiserror(core) + anyhow(cli) · dirs · tracing · tempfile(测试)

## Global Constraints

（每个 task 的要求都隐含包含本节，来自 CLAUDE.md §5/§7 + spec）

- Rust edition 2021，workspace resolver = "2"
- 路径绝不硬编码：用户目录一律 `dirs::home_dir()`，测试用 `Paths::new(tempdir)` 注入
- `~/.agents/skills/` 只放全局公共 skill，绝不写元数据文件进去；元数据统一收 `~/.skillkit/`
- core 用 `thiserror` 定义错误类型，cli 顶层用 `anyhow` 聚合
- 错误信息遵循「反馈引导行动」，不静默跳过（如 skill 未安装就提示 `skillkit install <id>`）
- 状态文件（registry/sources/config）原子写：写临时文件 + rename
- 日志用 `tracing`，不裸 `println!`（CLI 的用户可见输出可用 println，但业务日志走 tracing）
- 注释中文；commit message 用 Conventional Commits 中文
- 测试验证业务结果（install 后 canonical 有文件、Claude 能加载），不验证内部函数调用；git 操作用本地 bare repo 真跑
- M0 范围只到 global scope 的 install + 全局 Claude symlink；local scope 的 project 落地是 M1（但 install 的 `--scope local` 要能落 canonical 到 `~/.skillkit/skills/`，只是不 per-project apply）

## File Structure

```
skillkit/
  Cargo.toml                      # workspace 根（members: crates/core, crates/cli）
  crates/
    core/
      Cargo.toml                  # package: skillkit-core（lib）
      src/
        lib.rs                    # crate 入口，re-export 子模块
        paths.rs                  # Paths 结构（home/agents/claude/skm 路径解析）
        error.rs                  # SkillkitError（thiserror）
        config.rs                 # Config + Agent 能力（config.toml 读写）
        source.rs                 # SourceType/Source/SourcesStore（sources.toml 读写）
        registry.rs               # SkillMeta/Registry（registry.json 读写，id 为 key）
        git.rs                    # git 操作封装（clone/rev-parse，走 Command）
        install.rs                # install/uninstall（git clone/copy/npx + 登记 registry）
        symlink.rs                # 全局 Claude symlink 桥接（幂等）
    cli/
      Cargo.toml                  # package: skillkit-cli，bin name: skillkit
      src/
        main.rs                   # clap 入口（顶层 Cmd 枚举）
        commands/
          mod.rs
          source.rs               # source add/list/remove 子命令
          install.rs              # install/uninstall 子命令
  tests/
    m0_e2e.rs                     # M0 端到端：install git 源 → Claude symlink 落地 → 幂等
```

文件职责单一：`paths` 只管路径，`source`/`registry`/`config` 各管一种状态文件，`git` 封装 git 调用，`install` 编排（调 source+registry+git+symlink），`symlink` 只管链接。改一起的放一起。

```rust
    SkillAlreadyInstalled { id: String },

    #[error("git 操作失败：{message}")]
    Git { message: String },

    #[error("IO 错误：{0}")]
    Io(#[from] std::io::Error),

    #[error("序列化错误：{0}")]
    SerdeJson(#[from] serde_json::Error),

    #[error("配置解析错误：{0}")]
    TomlDe(#[from] toml::de::Error),

    #[error("配置序列化错误：{0}")]
    TomlSer(#[from] toml::ser::Error),

    #[error("canonical 目录创建失败：{0}")]
    CanonicalCreate(PathBuf),
```

```rust
    /// 默认只声明 Claude（需要 symlink 桥接）。
    fn default() -> Self {
        Self {
            agents: vec![Agent {
                name: "claude-code".to_string(),
                supports_symlink: true,
                reads_agents_dir: false,
            }],
        }
    }

impl Config {
    /// 读取 config.toml；文件不存在时返回默认配置（不报错，引导首次使用）。
    pub fn load(paths: &Paths) -> Result<Self> {
        let path = paths.config_path();
        if !path.exists() {
            return Ok(Self::default());
        }
        let content = std::fs::read_to_string(&path)?;
        let cfg: Config = toml::from_str(&content)?;
        Ok(cfg)
    }

    /// 原子写 config.toml（写临时文件 + rename）。
    pub fn save(&self, paths: &Paths) -> Result<()> {
        let path = paths.config_path();
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        let content = toml::to_string_pretty(self)?;
        atomic_write(&path, &content)?;
        Ok(())
    }
}

/// 原子写：先写同目录临时文件，再 rename 覆盖，避免半写状态。
fn atomic_write(path: &std::path::Path, content: &str) -> Result<()> {
    let tmp = path.with_extension("toml.tmp");
    std::fs::write(&tmp, content)?;
    std::fs::rename(&tmp, path)?;
    Ok(())
}
```

- [ ] **Step 4: 实现 SourcesStore**

在 `crates/core/src/source.rs` 的 `mod tests` 前补：
```rust
impl SourcesStore {
    pub fn load(paths: &Paths) -> Result<Self> {
        let path = paths.sources_path();
        if !path.exists() {
            return Ok(Self::default());
        }
        let content = std::fs::read_to_string(&path)?;
        Ok(toml::from_str(&content)?)
    }

    pub fn save(&self, paths: &Paths) -> Result<()> {
        let path = paths.sources_path();
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        atomic_write(&path, &toml::to_string_pretty(self)?)?;
        Ok(())
    }

    pub fn list(&self) -> &[Source] {
        &self.sources
    }

    pub fn add(&mut self, source: Source) -> Result<()> {
        if self.sources.iter().any(|s| s.name == source.name) {
            return Err(SkillkitError::SkillAlreadyInstalled { id: format!("source:{}", source.name) });
        }
        self.sources.push(source);
        Ok(())
    }

    pub fn remove(&mut self, name: &str) -> Result<&mut Self> {
        let before = self.sources.len();
        self.sources.retain(|s| s.name != name);
        if self.sources.len() == before {
            return Err(SkillkitError::SourceNotFound { name: name.to_string() });
        }
        Ok(self)
    }

    pub fn get(&self, name: &str) -> Result<&Source> {
        self.sources
            .iter()
            .find(|s| s.name == name)
            .ok_or_else(|| SkillkitError::SourceNotFound { name: name.to_string() })
    }
```

```rust
impl Registry {
    pub fn skill_id(source: &str, name: &str) -> String {
        format!("{source}/{name}")
    }

    pub fn load(paths: &Paths) -> Result<Self> {
        let path = paths.registry_path();
        if !path.exists() {
            return Ok(Self::default());
        }
        let content = std::fs::read_to_string(&path)?;
        Ok(serde_json::from_str(&content)?)
    }

    pub fn save(&self, paths: &Paths) -> Result<()> {
        let path = paths.registry_path();
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        atomic_write(&path, &serde_json::to_string_pretty(self)?)?;
        Ok(())
    }

    pub fn upsert(&mut self, meta: SkillMeta) {
        self.skills.insert(meta.id.clone(), meta);
    }

    pub fn get(&self, id: &str) -> Result<&SkillMeta> {
        self.skills.get(id).ok_or_else(|| SkillkitError::SkillNotInstalled { id: id.to_string() })
    }

    pub fn remove(&mut self, id: &str) -> Result<&mut Self> {
        if self.skills.remove(id).is_none() {
            return Err(SkillkitError::SkillNotInstalled { id: id.to_string() });
        }
        Ok(self)
    }
}
```

```rust
//! git 操作封装（走系统 git，避免 libgit2 编译依赖）。
use crate::error::{Result, SkillkitError};
use std::path::Path;
use std::process::Command;

/// clone 仓库到 target，可选 checkout 指定 ref。返回 HEAD 的 commit_sha。
pub fn clone(url: &str, target: &Path, ref_: Option<&str>) -> Result<String> {
    let mut cmd = Command::new("git");
    cmd.args(["clone", "--quiet", url]).arg(target);
    let status = run(&mut cmd)?;
    if !status {
        return Err(SkillkitError::Git { message: format!("clone 失败：{url}") });
    }
    if let Some(r) = ref_ {
        let ok = run(Command::new("git").args(["-C"]).arg(target).args(["checkout", "--quiet", r]))?;
        if !ok {
            return Err(SkillkitError::Git { message: format!("checkout {r} 失败") });
        }
    }
    rev_parse(target)
}

/// 返回 target 仓库 HEAD 的 commit_sha。
pub fn rev_parse(target: &Path) -> Result<String> {
    let out = Command::new("git")
        .args(["-C"]).arg(target).args(["rev-parse", "HEAD"])
        .output()
        .map_err(|e| SkillkitError::Git { message: e.to_string() })?;
    if !out.status.success() {
        return Err(SkillkitError::Git { message: String::from_utf8_lossy(&out.stderr).into() });
    }
    Ok(String::from_utf8_lossy(&out.stdout).trim().to_string())
}

fn run(cmd: &mut Command) -> Result<bool> {
    Ok(cmd.status().map_err(|e| SkillkitError::Git { message: e.to_string() })?.success())
}
```

```rust
//! install/uninstall：从源拉 skill 到 canonical，登记 registry。
use crate::error::{Result, SkillkitError};
use crate::git;
use crate::paths::Paths;
use crate::registry::{Registry, Scope, SkillMeta};
use crate::source::SourcesStore;

/// 安装：拉取到 canonical（按 scope 决定位置），记 commit_sha，登记 registry。
pub fn install(
    paths: &Paths,
    source_name: &str,
    skill_name: &str,
    scope: Scope,
) -> Result<SkillMeta> {
    let store = SourcesStore::load(paths)?;
    let source = store.get(source_name)?;

    let canonical_dir = match scope {
        Scope::Global => paths.agents_skills_dir(),
        Scope::Local => paths.skillkit_skills_dir(),
    };
    let target = canonical_dir.join(skill_name);
    if target.exists() {
        return Err(SkillkitError::SkillAlreadyInstalled { id: skill_name.to_string() });
    }
    if let Some(parent) = target.parent() {
        std::fs::create_dir_all(parent)?;
    }

    let sha = match source.source_type {
        crate::source::SourceType::Git => {
            let url = source.url.as_deref()
                .ok_or_else(|| SkillkitError::Git { message: format!("源 {} 缺少 url", source_name) })?;
            git::clone(url, &target, source.ref_.as_deref())?
        }
        crate::source::SourceType::Local => {
            let src = source.path.as_deref()
                .ok_or_else(|| SkillkitError::Git { message: format!("源 {} 缺少 path", source_name) })?;
            copy_dir(src, &target)?;
            git::rev_parse(&target).unwrap_or_else(|_| "unmanaged".into())
        }
        crate::source::SourceType::SkillsSh => {
            // M0：调 npx skills；这里给框架，实际 url 即 skills.sh 源
            let url = source.url.as_deref().unwrap_or(skill_name);
            crate::git::clone(url, &target, source.ref_.as_deref())?
        }
    };

    let id = Registry::skill_id(source_name, skill_name);
    let meta = SkillMeta {
        id: id.clone(),
        name: skill_name.into(),
        source: source_name.into(),
        scope,
        version: None,
        commit_sha: Some(sha),
        installed_at: now_iso(),
        canonical_path: format!("{}", target.display()),
    };
    let mut reg = Registry::load(paths)?;
    reg.upsert(meta.clone());
    reg.save(paths)?;
    Ok(meta)
}

/// 卸载：删 canonical + registry 记录。
pub fn uninstall(paths: &Paths, id: &str) -> Result<()> {
    let mut reg = Registry::load(paths)?;
    let meta = reg.get(id)?.clone();
    let target = std::path::PathBuf::from(&meta.canonical_path);
    if target.exists() {
        std::fs::remove_dir_all(&target).map_err(|_| SkillkitError::CanonicalCreate(target.clone()))?;
    }
    reg.remove(id)?.save(paths)?;
    Ok(())
}

fn copy_dir(src: &str, dst: &std::path::Path) -> Result<()> {
    let expanded = expand_tilde(src);
    let status = std::process::Command::new("cp")
        .args(["-R"]).arg(&expanded).arg(dst).status()
        .map_err(|e| SkillkitError::Git { message: e.to_string() })?;
    if !status.success() {
        return Err(SkillkitError::Git { message: format!("复制失败：{src}") });
    }
    Ok(())
}

fn expand_tilde(p: &str) -> String {
    if let Some(rest) = p.strip_prefix("~/") {
        if let Some(home) = dirs::home_dir() {
            return home.join(rest).to_string_lossy().into_owned();
        }
    }
    p.to_string()
}
```

```rust
/// 为 global skill 建 ~/.claude/skills/<name> → canonical 的 symlink。幂等。
pub fn ensure_global_claude(paths: &Paths, meta: &SkillMeta) -> Result<()> {
    if meta.scope != Scope::Global {
        return Ok(()); // 只桥接 global；local 的 project 落地在 M1

        if existing == target {

        std::fs::remove_file(&link).map_err(|e| SkillkitError::Git { message: e.to_string() })?;
    } else if link.exists() {
        // 真实目录占位（非 symlink）：报错引导，不静默删
        return Err(SkillkitError::CanonicalCreate(link));
    }
    #[cfg(unix)]
    std::os::unix::fs::symlink(target, &link)
        .map_err(|e| SkillkitError::Git { message: format!("symlink 失败：{e}") })?;
    Ok(())
}
```
