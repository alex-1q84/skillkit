# SkillKit M2 GUI（htmx）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 skillkit 加 `skillkit serve` 本地 web GUI，用 htmx + Askama 渲染四大视图，可视化操作 Sources/Skills/Profiles/Projects 并跑通 apply 闭环。

**Architecture:** 三层共享 core 不变。新增 `crates/server`（Axum 薄壳，每个 handler = `load → core 方法 → save → 渲染 Askama 片段`）。前端 htmx 局部替换 + SortableJS 拖拽，无独立前端工程。core 加文件锁原语保护 CLI/server 并发写。SSE 用 notify 监听 `~/.skillkit/` 跨进程刷新。

**Tech Stack:** Rust 2021；Axum 0.8、tokio 1、Askama 0.13（仅核心 `render()`，不引入 axum 集成 crate）、rust-embed 8、notify 8、fs2 0.4、tower 0.5（测试）；前端 htmx 2.x、SortableJS 1.15。

## Global Constraints

从 spec（`docs/superpowers/specs/2026-07-31-skillkit-m2-design.md`）与 `CLAUDE.md` 抄录，每个 task 隐含遵守：

- 元数据统一收 `~/.skillkit/`；`~/.agents/skills/` 与 `~/.claude/skills/` 绝不写元数据（§5 硬约束）。
- core 公开类型在 `lib.rs` 完整 re-export；core 业务逻辑零改动（M2 唯一新增是文件锁原语）。
- 路径不硬编码，一律 `Paths` / `dirs::home_dir()`。
- 文件原子写（`core::error::atomic_write`）；错误 core 用 `thiserror`、server 顶层用 `anyhow`。
- 日志用 `tracing`，不裸 `println!`（serve 启动 URL 提示除外）。
- 注释中文；代码命名跟随 Rust 惯例。
- 改完源码必跑 `make format && make lint`（clippy `-D warnings`，pedantic）。
- 集成测试放对应 crate `tests/`；测试跑 `git commit` 带 `-c user.email -c user.name`；用 `tempfile::tempdir()` 模拟 `~/.skillkit` + `~/.agents` + 项目目录。
- handler 测试用 `tower::ServiceExt::oneshot` 直接打 router，不起真实 TCP。
- 依赖版本钉死见 Task 2 的 `Cargo.toml`。

```rust
//! skillkit-server：Axum web server，调 skillkit-core，供 cli 的 serve 子命令调用。

use axum::{
    extract::State,
    extract::Request,
    middleware::{from_fn_with_state, Next},
    response::{IntoResponse, Response},
    routing::get,
    Router,
};
use skillkit_core::Paths;

#[derive(Clone)]
pub struct AppState {
    pub paths: Paths,
    pub token: String,
}

pub fn app(state: AppState) -> Router {
    // Axum 0.8 路由参数用 {token}（非 :token）。所有业务挂在 /{token}/ 下，layer 校验 token。
    let protected = Router::new()
        .route("/{token}", get(home_placeholder))
        .layer(from_fn_with_state(state.clone(), require_token));

    Router::new()
        .route("/ping", get(ping))
        .merge(protected)
        .with_state(state)
}

async fn ping() -> &'static str {
    "pong"
}

/// home 占位：Task 5 换成重定向 Projects。这里先返回 200 让 token 测试成立。
async fn home_placeholder() -> &'static str {
    "skillkit"
}

/// 校验 path 首段 == 预期 token，否则 404（不泄露路由存在性）。
async fn require_token(State(state): State<AppState>, req: Request, next: Next) -> Response {
    let token = req
        .uri()
        .path()
        .trim_start_matches('/')
        .split('/')
        .next()
        .unwrap_or("");
    if token != state.token {
        return axum::http::StatusCode::NOT_FOUND.into_response();
    }
    next.run(req).await
}

pub fn run(_port: u16) -> anyhow::Result<()> {
    Ok(())
}
```

```rust
use axum::{
    extract::{Path, Request, State},
    http::{header, StatusCode},
    middleware::{from_fn_with_state, Next},
    response::{IntoResponse, Response},
    routing::get,
    Router,
};
use rust_embed::RustEmbed;
use skillkit_core::Paths;

#[derive(RustEmbed)]
#[folder = "static/"]
struct Asset;

/// 静态资源（htmx/sortable/css），公开访问不校验 token（localhost 无泄露风险）。
async fn static_handler(Path(name): Path<String>) -> Response {
    match Asset::get(&name) {
        Some(file) => (
            [(header::CONTENT_TYPE, content_type(&name))],
            file.data.into_owned(),
        )
            .into_response(),
        None => StatusCode::NOT_FOUND.into_response(),
    }
}

fn content_type(name: &str) -> &'static str {
    if name.ends_with(".js") {
        "text/javascript; charset=utf-8"
    } else if name.ends_with(".css") {
        "text/css; charset=utf-8"
    } else {
        "application/octet-stream"
    }
}
```

```rust
/// 启动 web server：绑 127.0.0.1、生成随机 token、打印带 token 的 URL。
pub async fn serve(port: u16) -> anyhow::Result<()> {
    let paths = Paths::production();
    let token = uuid::Uuid::new_v4().simple().to_string();
    let state = AppState { paths, token: token.clone() };
    let app = app(state);
    let addr = format!("127.0.0.1:{port}");
    let listener = tokio::net::TcpListener::bind(&addr).await?;
    eprintln!("skillkit serve → http://{addr}/{token}/");
    axum::serve(listener, app).await?;
    Ok(())
}

/// 同步入口（供 cli 直接调用，内部建 runtime）。
pub fn run(port: u16) -> anyhow::Result<()> {
    let runtime = tokio::runtime::Runtime::new()?;
    runtime.block_on(serve(port))
}
```

- Consumes: `SkillkitError::Io`（已有，锁原语 IO 错误直接 `?`）。

**设计说明：** 互斥性靠 fs2 的 flock 跨进程生效（正是 CLI vs server 两进程场景）。同进程同文件不同 fd 的 flock 语义依平台而异，故单元测试只验证 acquire/release 基本路径，互斥性靠手动验证（起 CLI + server 同时写，观察超时报错）。

```rust
//! 文件锁：CLI/server 并发写 ~/.skillkit/ 状态文件时串行化。粒度到单文件，读不锁。
use crate::error::{Result, SkillkitError};
use crate::paths::Paths;
use fs2::FileExt;
use std::fs::OpenOptions;
use std::time::{Duration, Instant};

const LOCK_TIMEOUT: Duration = Duration::from_secs(5);
const RETRY_INTERVAL: Duration = Duration::from_millis(50);

/// 排他文件锁 guard。drop 自动释放。
pub struct FileLock {
    _file: std::fs::File,
}

impl FileLock {
    /// 默认 5s 超时（写操作用）。
    pub fn acquire(paths: &Paths, key: &str) -> Result<Self> {
        Self::acquire_with_timeout(paths, key, LOCK_TIMEOUT)
    }

    pub fn acquire_with_timeout(paths: &Paths, key: &str, timeout: Duration) -> Result<Self> {
        let lock_dir = paths.skillkit_dir().join(".lock");
        std::fs::create_dir_all(&lock_dir)?;
        let lock_path = lock_dir.join(format!("{key}.lock"));
        let file = OpenOptions::new()
            .create(true)
            .write(true)
            .read(true)
            .open(&lock_path)?;
        let deadline = Instant::now() + timeout;
        loop {
            match file.try_lock_exclusive() {
                Ok(()) => return Ok(FileLock { _file: file }),
                Err(_) => {
                    if Instant::now() >= deadline {
                        return Err(SkillkitError::LockTimeout { key: key.to_string() });
                    }
                    std::thread::sleep(RETRY_INTERVAL);
                }
            }
        }
    }
}

impl Drop for FileLock {
    fn drop(&mut self) {
        let _ = self._file.unlock();
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn lock_acquires_same_key_after_release() {
        let dir = tempfile::tempdir().unwrap();
        let paths = Paths::new(dir.path().to_path_buf());
        let l1 = FileLock::acquire_with_timeout(&paths, "registry", Duration::from_secs(1)).unwrap();
        drop(l1);
        // 释放后同 key 能再获
        let _l2 = FileLock::acquire_with_timeout(&paths, "registry", Duration::from_secs(1)).unwrap();
    }
}
```

```rust
/// 扫描项目 agents 的 skills 目录下 shared skill（真实目录，非 skillkit 管的 local）。
/// shared 由项目 git 管理，skillkit 只读展示。
pub fn scan_shared(project_root: &Path, agents: &[String]) -> Vec<String> {
    let mut found = Vec::new();
    for agent in agents {
        let dir = project_root.join(format!(".{}/skills", agent_dir_name(agent)));
        let Ok(entries) = std::fs::read_dir(&dir) else {
            continue;
        };
        for entry in entries.flatten() {
            let p = entry.path();
            let name = entry.file_name().to_string_lossy().into_owned();
            // 真实目录、非 symlink、无 skillkit-local 标记 → shared
            if p.is_dir() && !p.is_symlink() && !p.join(".skillkit-sha").exists() {
                found.push(format!("{agent}/{name}"));
            }
        }
    }
    found
}
```

fn status_fragment(state: AppState, token: String, proj: Project) -> Response {
    let reg = Registry::load(&state.paths).unwrap_or_default();
    let diff = compute_diff(&proj, &reg)
        .unwrap_or_else(|_| skillkit_core::ApplyDiff { expected: vec![], conflicts: vec![] });
    let status = build_status(&state.paths, &proj, &diff).unwrap_or(StatusView {
        expected: vec![],
        missing: vec![],
        extra: vec![],
        conflicts: vec![],
    });
    match StatusTpl { token: &token, status }.render() {
        Ok(html) => Html(html).into_response(),
        Err(e) => {
            tracing::error!(error = ?e, "渲染 status 片段失败");
            StatusCode::INTERNAL_SERVER_ERROR.into_response()
        }
    }
}

```rust
//! SSE：notify 监听 ~/.skillkit/，状态文件变化推送 changed 事件，前端按 scope 局部刷新。
use axum::extract::State;
use axum::response::sse::{Event, Sse};
use futures_util::stream::Stream;
use notify::{Config, EventKind, RecommendedWatcher, RecursiveMode, Watcher};
use std::path::PathBuf;
use tokio::sync::mpsc;
use tokio_stream::wrappers::ReceiverStream;

use crate::AppState;

pub async fn events(State(state): State<AppState>) -> Sse<impl Stream<Item = Result<Event, std::convert::Infallible>>> {
    let (tx, rx) = mpsc::channel::<Result<Event, std::convert::Infallible>>(16);
    let watch_dir: PathBuf = state.paths.skillkit_dir();

    let (notify_tx, mut notify_rx) = mpsc::channel::<notify::Event>(16);
    std::thread::spawn(move || {
        let tx = notify_tx;
        let mut watcher = match RecommendedWatcher::new(
            move |res: notify::Result<notify::Event>| {
                if let Ok(e) = res {
                    let _ = tx.blocking_send(e);
                }
            },
            Config::default(),
        ) {
            Ok(w) => w,
            Err(e) => {
                tracing::error!(error = ?e, "notify watcher 初始化失败");
                return;
            }
        };
        if let Err(e) = watcher.watch(&watch_dir, RecursiveMode::Recursive) {
            tracing::error!(error = ?e, "watch 失败");
        }
        // 保活：watcher 借用必须在本线程存活
        loop {
            std::thread::sleep(std::time::Duration::from_secs(60));
        }
    });

    tokio::spawn(async move {
        while let Some(e) = notify_rx.recv().await {
            if matches!(e.kind, EventKind::Modify(..) | EventKind::Create(..) | EventKind::Remove(..)) {
                if let Some(scope) = classify(&e) {
                    let event = Event::default().event("changed").data(scope);
                    if tx.send(Ok(event)).await.is_err() {
                        break;
                    }
                }
            }
        }
    });

    Sse::new(ReceiverStream::new(rx))
}

/// 按 path 推断变化 scope（registry/sources/profiles/projects/其它忽略）。
fn classify(e: &notify::Event) -> Option<String> {
    for p in &e.paths {
        let s = p.to_string_lossy();
        if s.contains("registry.json") {
            return Some("registry".into());
        }
        if s.contains("sources.toml") {
            return Some("sources".into());
        }
        if s.contains("/profiles/") {
            return Some("profiles".into());
        }
        if s.contains("/projects/") {
            return Some("projects".into());
        }
    }
    None
}
```
